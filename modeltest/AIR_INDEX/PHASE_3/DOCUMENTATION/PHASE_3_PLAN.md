# AIR-INDEX Phase 3 Plan

Phase 3 is additive. The original Phase 2 implementation is copied unchanged into this release and is not edited by Phase 3.

## Scope
- representative fare
- Base-100 route and booking-window indices
- airline analytical index
- configurable route weights
- overall AIR-INDEX aggregation
- quality metadata
- methodology versioning
- PostgreSQL persistence
- FastAPI API
- tests and integration path

## Explicitly out of scope
Forecasting, ML anomaly detection, recommendation, dashboard and mobile application remain later phases.
